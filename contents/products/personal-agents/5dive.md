5dive is an open-source (MIT) runtime for a team of AI agents on a Linux server you control.

**Runtime:** One install script or apt package on Ubuntu 22.04 or newer, or Docker. Each agent runs as its own Linux user and systemd service, and tasks live in SQLite. You chat with the team from the 5dive app (Android, Mac or web), Telegram or Microsoft Teams. It uses your own AI subscription or API key and needs no 5dive account.

**Acts on:** Agents share one task board, hand work to each other and check each other's results. Scheduled jobs (loops) run on their own, and a human gate holds a task until you decide.

**Extensions:** Agent types: Claude Code, Codex, OpenClaw, Hermes, Antigravity, Grok, Devin, OpenCode and Pi. Claude Code can also run on OpenRouter, DeepSeek, Kimi, Qwen and GLM models, or on local ones through Ollama, LM Studio or vLLM. A browser plugin gives agents a real Chrome with sessions you sign in to by hand.

**Notes:** Source [github.com/5dive-ai/5dive](https://github.com/5dive-ai/5dive). Positioned as an open-source alternative to Grok Bot and OpenAI Dots. A local-only mode cuts every outside connection.
