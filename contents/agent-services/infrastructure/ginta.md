Ginta builds and hosts websites for small businesses. An agent connected to its hosted MCP server (`https://ginta.app/mcp`, Streamable HTTP, OAuth sign-in) can create, publish and edit a site, then set up the parts Ginta runs on the server: contact forms, bookings, an online shop, events and a blog, with entries landing in the owner's inbox. Sites go live on a ginta.page subdomain; custom domains are on paid plans, and there is a free plan.

The vendor publishes an MCP server for this service.
