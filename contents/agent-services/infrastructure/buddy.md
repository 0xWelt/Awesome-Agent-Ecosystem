Run and monitor pipelines, deploy to environments, start isolated cloud sandboxes, publish packages, route domains, and read build logs.

The vendor publishes an MCP server, a CLI (`bdy`), and an Agent Skill ([buddy/buddy-plugin](https://github.com/buddy/buddy-plugin)) for this service.
