Free, searchable library of agent skills, MCP servers, repos and prompts in which each recommended item was statically scanned at a pinned commit for prompt injection, credential exfiltration, committed secrets and vulnerable dependencies, with flagged lines read by hand. Agents read each item's verdict, scanned commit and review status over JSON, REST or a vendor-hosted remote MCP server (`https://upskill.coach/mcp`), which also runs a daily check-in that tracks whether adopted items move one declared goal. Hosted, closed source.
