Watch hands off saved local AI coding sessions across Claude Code, Codex, OpenCode, Kimi CLI, Pi, and Grok. The CLI can preview a conversion, and when the target lacks an adapter it can export a read-only Markdown handoff. The desktop Claude Code → Codex flow previews the official import before confirmation.
